# Persian

Resources for learning Persian, organized by skill.

## Courses

- [Finglish](https://learnfinglish.com/) - Spoken Persian lessons in English letters with audio on every word and a speech check, with the first module free.

## Vocabulary & Dictionaries

- [Finglish Persian phrasebook](https://learnfinglish.com/tools/phrasebook) - 400+ everyday words and phrases in English letters with audio, no signup.
